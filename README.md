# Problem 1
Define a function called nth_powers that will take as input a positive integer n and a positive integer m and will print all of the positive nth powers 1^n, 2^n, 3^n, ..., m^n.

# Problem 2
Define a function called powers_of_two which will take as input a positive integer n and will print all of the powers of two that are less than or equal to n.

# Problem 3
Define a function called sum_of_odds which will take as an input a positive integer n and will return the sum of all the odd numbers that are less than or equal to n.

# Problem 4
Define a function called factorial_trailing_zeros which will take as an input a positive number n and return the number of trailing zeros in n!.

# Problem 5
Design a function sum_squares which takes in a positive number n and returns the sum of the square of the numbers from 1 to n: 1^2+2^2+3^2+...+n^2.

# Problem 6
Design a function sum_funct which takes in a positive number n and a function f returns the sum of the numbers from 1 to n with the function applied: f(1)+f(2)+...+f(n).

# Problem 7
Design a function mult_funct which takes in a positive number n and a function f and returns the product of the numbers from 1 to n after the function has been applied: f(1)\*f(2)\*...*f(n).

# Problem 8
Design a function combine_sequence which takes in a positive number n and two functions, one called combine and one called f, where f is the function as before and combine is the function which controls the manner in which the terms are combined.  If not otherwise specified, combine_sequence should default to summing the values of the function applied to the numbers from 1 to n.
